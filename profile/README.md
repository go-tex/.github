<h1 align="center">go-tex</h1>

<p align="center"><strong>Pure-Go TeX.</strong> Pure-Go (CGO=0), dependency-light, 100% test coverage, green across six 64-bit arches plus <code>js/wasm</code>.</p>

## Repositories

- [**math**](https://github.com/go-tex/math) — TeX math-mode typesetter → SVG via the OpenType MATH table (wasm-ready).
- [brand](https://github.com/go-tex/brand) — logos & icons.

## Conventions

Every module is `CGO_ENABLED=0` and standard-library-first, BSD-3-Clause licensed, with a ratcheted conformance/coverage gate in CI.
